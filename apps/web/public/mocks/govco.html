Del latido al veredicto.

  1. 1.0

    Latido.

    Cada dos horas, el agente despierta y consulta el SECOP: toda licitación nueva entra a la fila.

    Cloudflare Durable Objects — el agente vive, no se ejecuta por demanda.

  2. 2.0

    Cruce.

    Cada licitación se cruza contra nueve endpoints Croma: identidad mercantil, estados financieros, procesos judiciales y sanciones.

    SECOP → RUES → Supersociedades → Rama Judicial → Procuraduría / Contraloría

  3. 3.0

    Puntaje.

    Gemini puntúa el expediente completo y cita cada pieza de evidencia. El grafo de contratistas —nodos = NIT— conserva los vínculos entre empresas.

  4. 4.0

    Veredicto.

    Un solo motor emite dos caras: oportunidad para quien puede ganar limpio, bandera roja para lo que merece escrutinio.

La contratación pública ya es dato abierto. Centinela la mira por usted.
